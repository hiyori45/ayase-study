ことばテスト 試作版

内容:
- テストを複数登録・編集・削除
- 問題（ひらがな）と答え（カタカナ）を登録
- 10問をランダム出題
- 指/Apple Pencilで手書き
- 答えを表示して自分で確認
- データは同じブラウザ内に保存

使い方:
1. GitHubに新しいPublicリポジトリを作成
2. このZIPを展開し、中の index.html / manifest.json / sw.js をリポジトリ直下へアップロード
3. GitHubリポジトリの Settings > Pages で Deploy from a branch を選択
4. Branch: main / Folder: /(root) を選択して Save
5. 公開URLをiPadのSafariで開く
6. 共有メニュー > ホーム画面に追加

注意:
- 現在の試作版は端末・ブラウザごとのローカル保存です。
- SafariのWebサイトデータを消すと登録内容も消えます。
- 別端末とは同期されません。
- 手書き文字の自動認識・採点機能はありません。
- 10問以上登録したテストのみ開始できます。
