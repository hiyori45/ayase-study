# あやせスタディ

問題と答えを自由に登録して、手書きで学習するシンプルなWebアプリです。

## できること
- カタカナ、算数、漢字、英語など、教科を問わず問題と答えを登録
- テストごとに問題を管理・編集・削除
- 登録した問題から10問をランダムに出題
- iPadの指やApple Pencilで解答欄に手書き
- 答えを表示して自分で確認（自動採点・文字認識はしません）
- 登録データは利用中の端末・ブラウザ内に保存

## GitHub Pagesで公開
1. GitHubリポジトリの Settings → Pages を開く
2. Build and deployment の Source を「Deploy from a branch」にする
3. Branch を「main」、フォルダを「/(root)」にして Save
4. 数分後に表示されるURLをiPadのSafariで開く
5. Safariの共有メニューから「ホーム画面に追加」でアプリのように使えます

## 注意
データはブラウザのローカルストレージに保存されます。ブラウザが異なる場合や閲覧データを消去した場合は共有・復元されません。大切な問題データは別途控えを取ってください。
